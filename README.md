# ⚽ Dashboard Interactivo de Fútbol – Histórico FIFA / EA FC

Dashboard interactivo (Plotly) con el análisis histórico de valoraciones de ligas en la saga FIFA / EA FC.

🔗 **Demo en vivo:** https://Tomasmonserrat.github.io/dashboard-futbol/

## Cómo verlo
- Online: abrí el link de la demo.
- Local: descargá `index.html` y abrilo en cualquier navegador (necesita internet para cargar Plotly desde CDN).

## Stack
- Python + Plotly (generación de gráficos)
- HTML/CSS estático, sin backend
